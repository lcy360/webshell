## Patterns

- Titles perform better when they state the outcome before the tool.
- Numbers help: `5个终端`, `4个窗口`, `多线程`.
- The first paragraph should start from a concrete pain or result, not project background.
- Popular posts are less like README docs and more like workflow stories.
- The audience cares about: fewer windows, parallel AI coding, terminal aesthetics, mobile/remote control, and concrete setup commands.
- Save-worthy posts include enough setup detail to reproduce, but keep the command section short.
