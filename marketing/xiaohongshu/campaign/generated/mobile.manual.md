## Title

手机上继续vibe coding

## Body

我以前一直觉得手机写代码不现实，直到 AI CLI 开始长时间跑任务。

现在很多时候不是要在手机上写一大段代码，而是：

- 看 Claude 跑到哪了
- 给 Codex 补一句 review 要求
- 重启一下 npm dev
- 看一眼日志有没有报错
- 在外面临时处理一个 shell 命令

这些操作不需要完整 IDE，但需要能接上正在跑的 terminal session。

所以 Webshell 的手机端不是玩具功能。它的重点是：电脑上启动的 shell，手机浏览器打开后还能继续操作同一个 session。

我专门给移动端加了几个实用点：

1. 页面自动适配手机浏览器
2. terminal 占主屏幕
3. ↑、↓、Shift+Tab 放在顶部快捷操作区
4. 中文输入做了 IME 处理
5. session 切换走本地缓存，减少黑屏等待

配合 Cloudflare Tunnel，就可以在外面安全访问自己的 Webshell。安全上我建议绑定 localhost，用 HTTPS/tunnel，再加长密码，别裸奔到公网。

这个场景不是“手机替代电脑”，而是让长时间运行的 AI coding session 随时可以被接管。
